Online Quiz System :
The Online Quiz System is a web-based application developed using HTML, CSS, and JavaScript. It provides an interactive platform where users can attempt multiple-choice questions with features like timer, progress bar, dark mode, voice support, leaderboard, certificate generation, and AI-based question generation.
The project begins with a login page where users enter their name before starting the quiz. Questions are displayed one by one, and the system automatically calculates the score and stores leaderboard data using local storage. The application also includes speech synthesis and voice recognition features for a better user experience.
This project helps in understanding frontend development concepts such as DOM manipulation, event handling, responsive design, local storage, and API integration.

Features:
Login System
Multiple Choice Quiz
Timer and Progress Bar
Dark Mode
Voice Recognition
AI Question Generator
Leaderboard
Certificate Generation
Responsive Design

Technologies Used:
HTML5
CSS3
JavaScript
Gemini API

How to Run:
Download or clone the repository
Open the project folder
Run index.html in any browser
